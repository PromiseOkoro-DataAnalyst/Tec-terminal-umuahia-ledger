# Login email templates (Supabase Auth)

Supabase → Authentication → Emails → Templates. For each tab, paste the subject and
the whole HTML file into "Message body", then Save.

| Supabase tab | Subject | File |
|---|---|---|
| Confirm signup | Confirm your TecTerminal Ledger account | confirm-signup.html |
| Invite user | You’ve been invited to TecTerminal Ledger | invite-user.html |
| Magic link | Your TecTerminal Ledger sign-in link | magic-link.html |
| Change email address | Confirm your new email address | change-email.html |
| Reset password | Reset your TecTerminal Ledger password | reset-password.html |

The logo loads from the public "brand" storage bucket (email-logo.png).
